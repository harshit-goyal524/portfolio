PERSONAL PROJECT · 2025

Serverless Image Processing with Multi-User Concurrency and Distributed Computing

This project presents a scalable, intelligent image processing system designed to support multiple concurrent users. It leverages a hybrid architecture that integrates a Windows-based host machine, Linux-based local virtual machines (VMs), and serverless cloud containers deployed on Google Cloud Run. The system is built with modular microservices, real-time monitoring, and a lightweight custom load balancer that dynamically routes user tasks to the most optimal resource based on live system metrics.

PERSONAL PROJECT · 2024

Text Sentiment Analysis

This project aimed to address Text Sentiment Anlysis challenge by employing conventional machine learning approaches to analyze a dataset of over 30,000 tweets from Twitter. The objective was to implement and analyze different classifiers on the Sentiment Analysis Dataset, utilizing various preprocessing techniques (LDA & PCA), tokenizers (BERTTokenizer and TFIDtokenizer), and classifiers- Decision Trees, Random Forests, SVMs, Naive-Bayes, Perceptron and Logistic Regression, optimizing each to yield maximum accuracy by hyperparameter tuning. Finally, ensemble learning was employed to achieve optimum performance of the model.
